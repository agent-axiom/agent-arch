# Визуальный стандарт русской рукописи

Статус: обязательный стандарт для 56 рисунков и схем издательской рукописи.
Версия визуального языка: `agent-arch-book-v1`.

## Источник и форматы

- Mermaid-текст является источником правды для каждой схемы.
- SVG является основным векторным результатом сборки.
- PNG без альфа-канала, 300 dpi, является совместимым издательским резервом.
- Номер, название и поясняющая подпись хранятся в рукописи, а не внутри изображения.
- Альтернативное описание хранится в Markdown и переносится в DOCX при сборке.

## Два варианта одной системы

**Ключевой рисунок.** Нумерованная обзорная архитектура, цепочка доказательств
или схема жизненного цикла. Допускает две смысловые полосы и именованные группы.

**Рабочая схема.** Встроенная схема решения, состояния или процесса. Использует
тот же шрифт, палитру, стрелки и формы, но меньше узлов и декоративных элементов.

Различие вариантов определяется плотностью содержания, а не отдельной палитрой.

## Токены

| Роль | Значение |
|---|---|
| Шрифт | Arial, резервный sans-serif |
| Основной текст | `#1F2A3D` |
| Основная заливка узла | `#EEF4FA` |
| Основная граница | `#355A7A` |
| Дополнительная заливка | `#EDF8F3` |
| Решение | `#FFF4CC`, граница `#9B7A14` |
| Линии и стрелки | `#5E6B7D` |
| Фон группы | `#F7F9FC` |
| Граница группы | `#B7C4D6` |
| Толщина основной линии | 2,2 px в SVG |
| Скругление прямоугольника | 10 px в SVG |
| Минимальный печатный кегль | 8,5 пункта |

Ромб используется только для решения. Пунктирная связь означает контекст,
доказательство или контроль, который не является шагом основного процесса.
Цвет не используется как единственный носитель смысла.

## Компоновка

- В одном узле не более трех коротких строк.
- Длинный процесс делится на две горизонтальные смысловые полосы.
- Обзорная схема содержит не более 12-15 узлов; более сложный материал делится
  на обзор и детальную схему.
- Узкая вертикальная схема не допускается: отношение ширины SVG к высоте должно
  быть не меньше 0,72.
- Встроенный заголовок, подзаголовок, логотип и нижний колонтитул запрещены.
- Связи не должны пересекать подписи и создавать неоднозначный порядок чтения.

## Сборка и контроль

Единая команда рендерит три манифеста: 29 встроенных, 25 нумерованных и две
редакционные схемы. Mermaid локальной схемы не может переопределять тему.

Проверка выпуска должна подтверждать:

1. наличие 56 уникальных Mermaid-источников, SVG и PNG;
2. единый идентификатор темы во всех SVG;
3. минимальный печатный кегль 8,5 пункта;
4. отсутствие слишком узких схем и альфа-канала;
5. совпадение порядка изображений в Markdown, DOCX и PDF;
6. читаемость в цвете и оттенках серого при реальном печатном размере.

Таблицы остаются нативными таблицами Word: Mermaid для них не применяется.
