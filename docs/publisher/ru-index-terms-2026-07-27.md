# Рабочий словник предметного указателя

Дата сборки: 2026-08-01.

Назначение: передать индексатору устойчивый набор понятий и первичные
ссылки на главы. Номера страниц проставляются только после окончательной
верстки; этот файл не подменяет профессиональную индексную проходку.

## Правила

- **Предпочтительный термин** фиксирует написание в указателе.
- **Главы** задают первичные области поиска, а не готовые страницы.
- **См. также** связывает синонимы и соседние инженерные понятия.
- Имена полей, команд и программных интерфейсов индексируются отдельно
  только при наличии устойчивой читательской потребности.
