- `pdfinfo`: 443 страницы;
- размер страницы: `612 x 792 pts` (`letter`);
- размер файла: `5,761,977` bytes;
- producer: `Skia/PDF m152 Google Docs Renderer`.

Цветные страницы с новыми схемами найдены автоматически по насыщенности:

- страница 22 — рисунок 1.1;

Результат финального просмотра:

- все пять схем читаются;
- изображения не обрезаны;

- наложений текста и графики не обнаружено.

Полная постраничная вычитка всей рукописи в этом проходе не выполнялась: проверялся targeted visual QA для измененных страниц.
