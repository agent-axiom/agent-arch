# Errata

Status: skeleton for editor handoff.

## How to report

Use the public repository issue tracker after the companion URL is finalized.

Until publication, collect corrections in the editorial Google Doc or in the
publisher tracking issue.

## Errata policy

- Typos and formatting mistakes can be fixed in patch releases.
- Technical corrections should name the affected chapter, section and companion
  file.
- Fast-changing platform facts should include the date and source checked.
- Material guidance changes must be reflected in the changelog, not silently
  rewritten.

## Known placeholders

- Public companion URL is not finalized.
- Release version for the first book edition is not finalized.
