# Release decision record template

Status: release candidate template for adaptation.

Related chapters: 15, 16, 19, 20, 23.

Intended user: release owner, platform owner, verifier/eval owner, security
reviewer and accountable product owner deciding whether an agentic change can
advance to the next rollout wave.

What to adapt: release waves, evidence requirements, accepted-risk roles,
observation windows, stop criteria, rollback owners and residual-risk language.

Limitations: this template records an engineering release decision. It does not
replace formal risk acceptance, change-management or compliance workflows where
those are required.
