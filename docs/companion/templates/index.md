# Companion templates

Status: release candidate route for editor handoff.

Эти шаблоны разгружают печатную рукопись. В книге остается объяснение
архитектурного решения, а здесь - заполняемые рабочие формы.

## Templates

- [Capability contract](capability-contract.md)
- [Release decision record](release-decision-record.md)
- [Incident record](incident-record.md)

Each template now has a release-candidate header with related chapters,
intended user, adaptation notes and limitations.

## Release rule

Перед публикацией у каждого шаблона должен быть header:

- related chapter;
- intended user;
- status: example, draft for adaptation, or recommended structure;
- what must be adapted by the reader;
- limitations and non-goals.
