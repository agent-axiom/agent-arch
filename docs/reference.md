# Справочный слой

Если книга объясняет, **почему** безопасная агентная система должна быть устроена именно так, то справочный слой помогает быстро перейти к вопросу **что именно нужно зафиксировать в артефактах, схемах и правилах**.

Эта секция полезна, если тебе нужно:

- быстро найти нужную contract page;
- подготовить design review или rollout review;
- вытащить reusable artifacts для своей команды;
- перейти от главы книги к более прикладной инженерной форме.
