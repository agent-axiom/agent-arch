# Часть III. Память и знания

На этом этапе агент у тебя уже не просто рассуждает и не просто безопасно ходит в инструменты. Теперь возникает следующий соблазн: дать ему память, чтобы он не начинал каждый run с нуля.

Это правильный шаг, но именно здесь многие системы начинают тихо накапливать долг:

- сохраняют в память все подряд;
- не различают profile memory и рабочий контекст;
- тащат недоверенный текст обратно в prompt без проверки;
- пишут в память прямо в hot path, где ошибка мгновенно становится persistent.

В этой части мы разберем, как сделать память полезной, но не превратить ее в долговременный источник инъекций, утечек и странного поведения.
