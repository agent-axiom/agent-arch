# 第四部分：工具与执行

到这里为止，我们已经有了三个重要层次：

- 平台架构；
- 安全边界；
- 记忆与 retrieval discipline。

现在该进入真正的执行层了，也就是智能体不再只是“聪明的文本”，而是开始实际做事的地方。

最贵的问题通常正是在这里出现：

- 错误的 tool calls；
- 意外的 side effects；
- 不稳定的 integrations；
- 没有 idempotency 的重复操作；
- 对外部系统过于宽松的访问。

这一部分会拆解 execution layer 应该如何设计，让智能体不是直接伸手去碰外部世界，而是通过清晰的契约、限制和安全网关来工作。
